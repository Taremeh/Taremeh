**Human–AI collaboration in software engineering.** I study how increasingly autonomous AI reshapes the way
people build, understand, and control software. As agents take over more of the work, I examine how developers' attention, understanding, and reliance on AI
shift, and how these changes affect our ability to critically assess the software AI produces.

## Research

**Grasping AI Reliance in Program Comprehension and Coding through the AIRELI Persona Taxonomy** · ICPC '26<br>
Three ways developers rely on AI, and the comprehension debt that fast AI-assisted work can hide.<br>
[Paper](https://doi.org/10.1145/3794763.3794804) · [Project site](https://aireli.hasel.dev/) · [Study task](https://github.com/Taremeh/aireli-lecture-task)

**An Eye for AI: Eye-Tracking the Micro-Interruptions of GenAI Code Suggestions** · ICSE '26 · ACM SIGSOFT Distinguished Artifact Award<br>
Eye tracking how developers attend to inline AI code suggestions, from display to decision.<br>
[Paper](https://doi.org/10.1145/3744916.3773132) · [Project site](https://eye-for-ai.hasel.dev/) · [Study task](https://github.com/Taremeh/t-rex-game)

**PosEyeDOM: Lightweight Positional Copilot Suggestion Logger for Eye-Tracking Applications using the DOM** · ICSE '26 Demo<br>
A browser extension that logs where each Copilot suggestion is on screen, so gaze can be mapped to it.<br>
[Paper](https://doi.org/10.1145/3774748.3787608) · [Project site](https://poseyedom.hasel.dev/) · [Code](https://github.com/Taremeh/PosEyeDOM)

**Predicting Code Comprehension: A Novel Approach to Align Human Gaze with Code using Deep Neural Networks** · FSE '24<br>
The first neural network that aligns a developer's gaze with the code they read, to predict comprehension and perceived difficulty.<br>
[Paper](https://doi.org/10.1145/3660795) · [Code and data](https://github.com/Taremeh/predicting-code-comprehension-eye-tracking)

## Things I build

Agentic micro-apps and micro-services I build with AI coding agents: tools for new forms of human–AI
interaction, and for working more productively with AI. One of them is public here:
[**AI Tempomat**](https://github.com/Taremeh/tempomat-ai), a macOS menu bar gauge that shows how fast your
agents use up your Claude Code limits. The others are described on [alakmeh.ch](https://alakmeh.ch).
